# OHADA — Plan Comptable Syscohada

## Overview

L'OHADA (Organisation pour l'Harmonisation en Afrique du Droit des Affaires) a adopté le **SYSCOHADA** (Système Comptable OHADA) comme plan comptable standard pour les États membres.

## Règles d'évaluation

### Évaluation des immobilisations

- **Prix d'achat** + **frais直接s** - **remises commerciales**
- Dépréciation obligatoire selon le plan d'amortissement

### Évaluation des stocks

- **Coût d'acquisition** ou **coût de production**
- Méthode du **CMP** (Coût Moyen Pondéré) ou **FIFO**
- Dépréciation si valeur actuelle < valeur comptable

### Évaluation des créances

- Dépréciation sur base individuelle
- Taux de provision selon l'ancienneté :
  - 6 mois à 1 an : 20%
  - 1 an à 2 ans : 50%
  - Plus de 2 ans : 100%

## Amortissements

### Méthodes

1. **Linéaire** — quote-part constante
2. **Dégressif** — taux appliqué à la valeur nette
3. **Unitaires** — pour les immobilisations spécifiques

### Durées indicatives OHADA

| Catégorie | Durée |
|-----------|-------|
| Bâtiments | 20-25 ans |
| Matériel outillage | 5-10 ans |
| Matériel transport | 5 ans |
| Mobilier bureau | 5-10 ans |
| Brevets, licences | Durée du droit |
| Logiciels | 3-5 ans |

## Clôture d'exercice

### Étapes

1. **Inventaire physique** des stocks
2. **Écritures de régularisation**
   - Charges constatées d'avance
   - Produits constatés d'avance
   - Charges à payer
   - Produits à recevoir
3. **Amortissements** de l'exercice
4. **Dépréciations** et provisions
5. **Écritures de clôture** des comptes de charges et produits
6. **Détermination du résultat**
7. **Affectation du résultat**

## Implémentation dans FIP

### Modèle de données

```python
class Account(Base):
    """Plan comptable OHADA"""
    code = Column(String(8), nullable=False, unique=True)
    label = Column(String(255), nullable=False)
    account_class = Column(Integer, nullable=False)  # 1-8
    is_analytical = Column(Boolean, default=False)
    is_third_party = Column(Boolean, default=False)
    nature = Column(String(20))  # debit/credit/both
```

### Règles de validation

```python
class AccountValidator:
    """Validation conforme OHADA"""
    
    def validate_journal_entry(entry: JournalEntry) -> bool:
        # Partie double obligatoire
        total_debit = sum(line.debit for line in entry.lines)
        total_credit = sum(line.credit for line in entry.lines)
        
        if total_debit != total_credit:
            raise ValidationError("Écriture non équilibrée")
        
        # Au moins 2 lignes
        if len(entry.lines) < 2:
            raise ValidationError("Écriture doit avoir au moins 2 lignes")
        
        return True
```
