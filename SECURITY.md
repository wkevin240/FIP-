# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue or pull request.

While this repository is private, contact the repository owner through their
GitHub profile. After the repository becomes public, use GitHub's private
vulnerability reporting feature when it is enabled for this repository. Include
the affected version or commit, steps to reproduce, and the impact. Do not
include real customer data or credentials in the report.

## Supported versions

Security fixes are made against the latest code on `main`. No other release
line is currently designated as supported.
